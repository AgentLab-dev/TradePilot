# News portal sessions

Do **not** put WSJ / MarketWatch passwords in this folder.

Login methods (skill `news-portals`):

1. Cursor browser — user completes Sign In (2FA ok).
2. Safari or Chrome tab that is already signed in (`news_portals.py --safari`).
3. Public RSS — no login.

Optional local reminder file (gitignored): copy `portals.example.json` to `portals.json` with the email you use at WSJ. Never the password.
