# List → ticket

**Logged miss:** OKTA (8/26), SNOW (9/2), CRM (8/26 + Sep board), HPE (9/2–9/3).
All were **on a list**. None had a **go-shaped ticket in time**. After ≥+7% we
correctly said STAND — which made the miss look like we never helped.

## The hole

| Stage | Wrong | Right |
|---|---|---|
| Name on IBD / T7 / NEWS | "We're watching" | Written **ticket** or **SKIP (gate)** the same day |
| Into-print | Homepage NVDA buries OKTA | `{TICKER} earnings` + PPS-T1 score **before 4:00 ET** |
| EM <15% but analog ≥1.5× | STAND-and-forget (SNOW) | ARM ticket + second-name card |
| User one-name last-90 | Other analogs have no path | Second-name **card** still required |
| After ≥+7% AH | Suggest go into the rip | STAND the ripped name; log the hole if no pre-move ticket |

## Who must get a line (same session)

Every name that is any of:

- IBD 50 / Sector Leaders / Big Cap 20 / Funds / Spotlight (live capture)
- PPS-T7 **🟢 ON**
- ALWAYS / category map (cyber, AI/data, gold unique, etc.)
- NEWS / Reddit-named **and** large-cap or sleeve leader

Write one row in `print_monitor.md` **or** `catalyst_cards.md` **or** the daily
lesson. Tokens:

| Token | Meaning |
|---|---|
| **TICKET** | Structure, expiry, cap, clock (last-90 / first-30 / ARM). Waits for **go**. |
| **SKIP** | Named gate: EM fail + no analog, liquidity fail, leftover ban **with** unique replacement already in the five, chase ≥+7%, credit-through-print. |
| **HOLE** | Was on a list, no TICKET/SKIP before the move, then ripped. Append `agent_learning_log.md`. |

A ⚪ checkbox on STKK is **not** TICKET. "Board" is **not** TICKET (AUGO/ECO/CRM 9/9).

## Promote to TICKET (do not wait for mega-cap)

1. **0d/1d print:** run PPS-T1. EM ≥15% + beat/theme → **TAKE** ticket before 4:00 ET (OKTA).
2. **Analog ≥1.5× EM:** ARM ticket even if EM <15% (`print-analog-vs-em`). Second-name card required (SNOW).
3. **Non-print list leadership:** mix-rule slot. Score live 4-model + liquidity. TICKET or SKIP the same day — not board.
4. **Beat + dump inside ±7%:** do not mark DONE. Write reclaim + IR cards (HPE / SNDK).

## Fail the run if

- An IBD 50 / Big Cap 20 / Sector Leader / PPS-T7 ON name has **neither** TICKET nor SKIP.
- A later ≥+7% mover was on yesterday's list and the log has no TICKET/SKIP from before the move.
- Analog ≥1.5× EM has no second-name ticket.
- `{TICKER} earnings` was skipped because the homepage was NVDA.

Wait for **go**. Anti-chase after ≥+7% AH still applies.
