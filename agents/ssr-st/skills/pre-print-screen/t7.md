1. `{TICKER} earnings` on WSJ, MarketWatch, Yahoo, CNBC, IR — not homepage-only. On FULL CHECK this is a fail if a 🟢 ON name has no ticker-earnings line (step 9).
2. Peer tape in its category
3. `whale_check.py SYM --to <next monthly>` — EM%, ATM IV, OTM call OI wall
4. `get_earnings_results` — consecutive beats, last-4 surprise %
5. IBD overlap if lists were captured
6. Theme in the last ~14d

as the only name, skipping a category print because whale is 🔴.
