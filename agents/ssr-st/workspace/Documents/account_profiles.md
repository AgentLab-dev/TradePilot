# Account Profiles

_Scope every trade recommendation to the correct account. Never bleed one account's rules
into another (the SPCX lesson — $1k caution was wrongly applied to a personal-account IPO
allocation). **Confirm/update with the user; do not assume.**_
_Last updated: June 12, 2026._

---

## 1. $1k agent account (the managed account)

| Field | Value |
|---|---|
| Size | ~$1,000 |
| Purpose | Agent-managed; STKK / Three Good / STNOW disciplined trades |
| Risk per trade | ≤ 15–20% of account max loss |
| Position sizing | 1 contract on high-beta names; capital-efficient names favored |
| Gates | R:R ≥ 2:1; no chasing; macro/event gate; credit-to-width ≥ 25–30% for spreads |
| Style | Defined-risk options + small share positions; preserve capital first |
| Current open | HOOD $93/$98 call debit spread (2 contracts), breakeven $95, max profit ≥$98 |

## 2. Personal account

| Field | Value |
|---|---|
| Size | **$25k–$100k** |
| Per-trade risk % | **~10% baseline, sizes up on high-conviction names** (variable) |
| Goals | **Steady small green / income + swing trades (days–weeks)** — "make money, exit green" |
| IPO Access | **Yes** — Robinhood IPO applicants allocated at the fixed offer price (e.g. SPCX @ $135). Allocations here are **flip candidates**. **Default = ASK each time** (user chose case-by-case). |
| Style / instruments | **Shares + options** |
| Notes | Larger than the $1k account (placed a 200-share SPCX allocation order). Do NOT apply $1k rules here. |

---

## Rule of use

1. **Always ask which account** a trade is for (STNOW Step 0, intake Q1).
2. Apply that account's risk profile — not the other's.
3. For the personal account, fill the `_to confirm_` fields by **asking**, then update this file.
4. IPO Access allocations (personal account) = advantaged entries (NOT a chase). User chose **case-by-case → ASK each time**: confirm flip-vs-hold and the exit target before giving a verdict, per the STNOW IPO-allocation branch.
